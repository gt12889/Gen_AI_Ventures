# Welcome to my GenAI Business Implementation project


This project is built with .

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS


Project Summary

Purpose
The goal of this project was to help our partner company build an internal product for competitive market analysis. The tool is intended for proprietary use and designed to support better decision-making in fast-moving markets.

Problem We Addressed

The company did not have a product in place for market or competitor analysis

There was limited understanding of the current AI-driven analysis landscape

No clear structure existed for turning raw market data into actionable insights

Because of this, the business lacked a reliable way to evaluate competitors, trends, and opportunities.
